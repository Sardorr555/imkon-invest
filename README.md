# Imkon

Адаптивная платформа для инвесторов и предпринимателей на русском, английском и узбекском (латиница): два опросника (9 и 10 вопросов), готовые и свободные ответы, сохранение контактов и диалогов, серверная интеграция RAGFlow и скачивание результата. Выбор языка сохраняется в браузере; переключение не стирает ответы. Свободные ответы и ранее созданные AI-отчёты сохраняются на исходном языке, новый AI-анализ запрашивается на выбранном языке.

Сборка (Node.js 22+): `npm run build`, затем `npm run validate` и `npm test`. Превью: `npm run preview` (тестовая учётная запись администратора, данные только в памяти). `web/locales.js` — строки и вопросы, `web/app.js` — интерфейс, `worker/server.js` — сервер.

## Админ-панель

Откройте пункт «Админ-панель» или `/admin`. Доступ проверяется на каждом запросе по доверенным серверным заголовкам личности Sites. Серверная секретная переменная `ADMIN_EMAILS` содержит разрешённые email учётных записей ChatGPT через запятую. Email, введённый в профиле пользователем, **не даёт прав администратора**. По умолчанию при настройке добавлен владелец сайта.

В панели доступны: все пользователи с именем/email/телефоном/датой регистрации, поиск среди загруженных записей, пагинация «Загрузить ещё», обе анкеты пользователя, последние результаты, общая история анализов и скачивание отчёта. Каждый новый успешный анализ или сводка сохраняется отдельным снимком в `analyses/`. Снимок включает ответы на момент анализа и не меняется после редактирования анкеты. Старые результаты первой версии также читаются из сохранённых анкет. Все admin API возвращают 403 для пользователя вне списка разрешённых администраторов. Переводы интерфейса не изменяют исходные ответы/отчёты.

## Доступ и хранение

Вход предоставляется платформой Sites через ChatGPT. Профиль содержит имя, email, телефон и время согласия. R2 BUCKET хранит данные под серверным идентификатором пользователя. Владение email и телефоном **не подтверждается**. Независимая регистрация с email/SMS-кодами ещё требует провайдера аутентификации и отправки кодов. Главная страница публичная. Для личного кабинета и анкет требуется вход через ChatGPT; админ-панель дополнительно проверяет серверный список ADMIN_EMAILS.

## Подключение RAGFlow

Задайте серверные переменные Sites: `RAGFLOW_BASE_URL` (HTTPS), `RAGFLOW_API_KEY` (секрет), `RAGFLOW_INVESTOR_CHAT_ID` и `RAGFLOW_BUSINESS_CHAT_ID`. По роли выбирается свой чат; `RAGFLOW_CHAT_ID` остаётся необязательным резервным общим чатом. Не помещайте ключ в браузерный код или репозиторий. Опциональная `RAGFLOW_COMPLETIONS_PATH` поддерживает шаблон `{chat_id}` для старой версии. По умолчанию: `POST /api/v1/openai/{chat_id}/chat/completions`, `model: "model"` (модель из настроек выбранного чата), `stream:false`. Документация: https://ragflow.io/docs/http_api_reference

Для Swipies используется базовый адрес `https://api.swipies.app`, чат `inverstor_imkonTop` для инвесторов и `client_imkonTop` для предпринимателей. Настройки хранятся в серверном окружении Sites. Ключ не включается в исходники или HTML. В записи анализа сохраняется ID использованного чата для проверки маршрутизации.

`RAGFLOW_API_MODE=native` включает штатный `POST /api/v1/chat/completions` с `chat_id`, `question` (полные инструкции и все ответы), `stream:false`. Ответ читается из `data.answer`; ID созданной сессии сохраняется вместе с отчётом. Этот режим предусмотрен для Swipies, где при проверке OpenAI-совместимый обработчик возвращал `NameError: LLMType is not defined`. Без режима native остаётся совместимый формат OpenAI. Для каждого нового анализа создаётся отдельная сессия, чтобы не смешивать разные анкеты и пользователей.

В RAGFlow передаются роль и весь диалог вопрос–ответ. Контактные данные не передаются. Prompt запрашивает профиль, пробелы, риски и следующие шаги без выдуманных фактов. Ответ модели отображается как текст. Без конфигурации выводится явно обозначенная сводка анкеты. При сбое сервиса ответы сохраняются и доступен повтор.

## Для полноценного запуска

Подключить RAGFlow и проверить качество на ваших примерах; подключить email/SMS-аутентификацию; подготовить политику обработки данных и определить аудиторию. Реального каталога и подбора инвесторов в текущей версии нет.
